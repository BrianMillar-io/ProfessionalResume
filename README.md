## Featured project

### [SocialMediaMarketingTool](https://github.com/BrianMillar-io/SocialMediaMarketingTool)

An automation pipeline for my electronic music project, BLCK.MSSV. It turns hour-long DJ mixes into short vertical videos and publishes them to Instagram on a schedule with no manual steps.

- Analyzes each mix to find its biggest drops and cuts a 24-second clip around one
- Renders 1080x1920 reels with audio-reactive visuals, or reframes 360-degree gig footage into a vertical shot aimed at the most active part of the scene
- Rotates mixes and visual styles so posts never repeat back to back
- Publishes through the official Instagram Graph API, with the access token stored in the macOS Keychain and posts run by a scheduled launchd job

Built with Python, ffmpeg, NumPy, Pillow, the Instagram Graph API and macOS launchd.
